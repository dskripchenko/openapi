# Темы

Справочник и редактор рисуются токенами
[`@dskripchenko/ui`](https://github.com/dskripchenko/ui) — его поверхностями,
цветами текста, границами, акцентным и статусными цветами — и его
компонентами. Какую бы тему ни показывал кит, пакет следует за ней: своя
тема кита перекрашивает и его.

## Тёмная тема

Настраивать нечего. Кит переключает темы атрибутом `data-theme` на `<html>`
(или любом предке), а цвета пакета берутся из токенов кита:

```html
<html data-theme="dark">
```

Чтобы следовать системной настройке, ставьте атрибут из приложения — это
делает `useTheme()` кита, — и справочник с редактором последуют за
остальной страницей.

Фон страницы задаёт хост: поставьте его на `body` или контейнер, например
равным `--uid-surface-base` кита.

## Переменные

Несколько собственных параметров пакета — пользовательские свойства CSS.

| Переменная | По умолчанию | Для чего |
|---|---|---|
| `--oa-sticky-top` | `0px` | Отступ сверху для прилипающих навигации, колонки примеров и дерева редактора, а также позиция прокрутки к якорям — задайте равным высоте фиксированной шапки. |
| `--oa-source-height` | `560px` | Высота режима исходника в редакторе. |
| `--oa-nav-width` | `272px` | Ширина колонки навигации справочника. |
| `--oa-gap` | `24px` | Промежуток между колонками и между блоками операции. |
| `--oa-radius` | `8px` | Радиус скругления панелей. |
| `--oa-mono` | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | Моноширинный шрифт путей, типов и кода. |
| `--oa-get` / `--oa-get-bg` | `var(--uid-info)` / `var(--uid-info-subtle)` | Метка `GET`: текст / фон. |
| `--oa-post` / `--oa-post-bg` | `var(--uid-success)` / `var(--uid-success-subtle)` | `POST`. |
| `--oa-put` / `--oa-put-bg` | `var(--uid-warning)` / `var(--uid-warning-subtle)` | `PUT`. |
| `--oa-patch` / `--oa-patch-bg` | `var(--uid-warning)` / `var(--uid-warning-subtle)` | `PATCH`. |
| `--oa-delete` / `--oa-delete-bg` | `var(--uid-danger)` / `var(--uid-danger-subtle)` | `DELETE`. |
| `--oa-other` / `--oa-other-bg` | `var(--uid-text-secondary)` / `var(--uid-color-bg-subtle)` | `HEAD`, `OPTIONS`, `TRACE`. |

## Где их задавать

У `--oa-sticky-top` и `--oa-source-height` нет собственного значения,
поэтому их можно задать где угодно выше компонента — на `:root` или на
контейнере:

```css
:root {
  --oa-sticky-top: 64px;    /* the height of the site header */
}
```

Остальные переменные объявлены на корневом элементе самого компонента
(классы `.oa-reference` и `.oa-editor`) — благодаря этому их значения по
умолчанию следуют теме. Чтобы их изменить, задавайте их на этих классах:
значение на `:root` или на контейнере там перекрывается:

```css
.docs .oa-reference {
  --oa-nav-width: 320px;
  --oa-get: #0284c7;
  --oa-get-bg: #e0f2fe;
}

[data-theme='dark'] .docs .oa-reference {
  --oa-get: #7dd3fc;
  --oa-get-bg: #0c4a6e;
}
```

Если не трогать цвета методов, они остаются согласованными со статусными
цветами кита в обеих темах.

## Цвета кода

Блоки кода — примеры запроса, примеры значений, ответы и исходник в
редакторе — используют подсветку кода кита и его токены `--uid-code-tok-*`;
перекрашивайте их через кит.

## Имена классов

У элементов стабильные имена классов с префиксом `oa-` — `oa-reference`,
`oa-nav`, `oa-op`, `oa-method oa-method--get`, `oa-schema`, `oa-tryit`,
`oa-editor` и так далее — для стилизации снаружи. Якоря операций и схем —
это id их элементов: `operation/{id}` и `schema/{name}`.
