# OpenApiEditor

Визуальный редактор документов OpenAPI, с исходником и просмотром рядом с
формами.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { OpenApiEditor } from '@dskripchenko/openapi/vue'

const text = ref(initialYaml)
</script>

<template>
  <OpenApiEditor v-model="text" locale="en" />
</template>
```

## Свойства и события

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `modelValue` | `string` | — | Текст документа, YAML или JSON. Используйте `v-model`. |
| `view` | `'visual' \| 'source' \| 'preview'` | `'visual'` | Показанный режим. Редактор открывается в нём, а новое значение переключает на него; пользователь по-прежнему может переключать режимы на панели. |
| `locale` | `string` | — | `'en'` или `'ru'`; также задаёт локаль кита внутри, как в [справочнике](reference.md#языки). |
| `labels` | `Partial<EditorLabels>` | `{}` | Замены отдельных строк редактора. |
| `send` | `SendFn` | `fetch` | Передаётся в try-it просмотра. См. [прокси](reference.md#отправка-через-свой-сервер). |
| `referenceLabels` | `Partial<OpenApiLabels>` | `{}` | Строки просмотра: `labels` справочника. |
| `snippetTargets` | `SnippetTarget[]` | все 13 | Языки примеров в просмотре. |
| `baseUrl` | `string` | origin страницы | База для относительных URL серверов в просмотре. |
| `external` | `(url: string) => unknown \| undefined` | — | Загружает внешние документы `$ref` в просмотре, как в [справочнике](reference.md#внешние-ссылки). |
| `newFormat` | `'yaml' \| 'json'` | `'yaml'` | Формат документа, созданного из пустого текста. |

| Событие | Данные | |
|---|---|---|
| `update:modelValue` | `string` | Новый текст после каждого изменения в любом режиме. |
| `issues` | `DocumentIssue[]` | Проблемы документа — при монтировании и при каждом их изменении. Текст, который не разбирается, приходит одной проблемой с `severity: 'error'` и строкой и столбцом парсера. |

Текст — единственное состояние, которое редактор делит с хостом: сохраняйте
его так же, как любой другой текст. Новый `modelValue` снаружи заменяет
редактируемый документ.

## Формат сохраняется

Редактор читает текст как YAML или JSON (JSON, если он начинается с `{` или
`[`) и записывает обратно в том же формате. На панели есть переключатель
YAML / JSON, который переписывает весь документ в другом формате.

Версия тоже сохраняется: формы правят документ как есть, а не
нормализованную копию, поэтому документ OpenAPI 3.0 остаётся 3.0. Там, где
версии записывают одно и то же по-разному, формы следуют версии документа —
поле, допускающее null, становится `nullable: true` в 3.0 и
`type: [string, 'null']` в 3.1.

## Три режима

Переключаются панелью сверху.

**Visual (конструктор).** Слева — дерево документа: сведения, серверы, теги,
схемы авторизации, пути с их операциями и схемы. `+` рядом с разделом
добавляет элемент. Справа — форма выбранного узла.

**Source (исходник).** Текст с подсветкой, номерами строк и списком
найденных проблем под ним. Ввод здесь правит текст как есть — форматирование
и комментарии остаются. Tab вставляет два пробела. Очень большие тексты
(больше примерно 150 000 символов) показываются без подсветки, чтобы ввод
оставался быстрым.

**Preview (просмотр).** Документ, отрисованный
[`OpenApiReference`](reference.md), с `locale`, `send`, `referenceLabels`,
`snippetTargets`, `baseUrl` и `external` редактора; try-it там работает. Просмотр не трогает `location.hash`.

## Что покрывают формы

- **Сведения (info)** — название, версия, краткое описание, описание
  (markdown), условия использования, имя, email и URL контакта, название и
  URL лицензии.
- **Серверы** — URL и описание каждого сервера и его переменные со
  значением по умолчанию и списком допустимых значений.
- **Теги** — имя и описание; их порядок — порядок разделов в справочнике.
- **Схемы авторизации** — тип (`apiKey`, `http`, `oauth2`,
  `openIdConnect`, `mutualTLS`) и поля этого типа: куда идёт ключ API и его
  имя; схема http и формат bearer-токена; поток OAuth2 с его URL и scope (по
  одному `name: description` на строку); URL OpenID Connect.
- **Пути** — шаблон пути (переименовывается, когда поле теряет фокус;
  должен начинаться с `/`), его методы и «Add operation».
- **Операции** — краткое описание, описание, `operationId`, теги, признак
  устаревшей операции; параметры (имя, `in`, обязательность, описание,
  схема), с добавлением в один щелчок для `{names}` пути, у которых ещё нет
  параметра; тело запроса с типами содержимого и их схемами; ответы по кодам
  статуса с описанием и содержимым; авторизация — как у документа, без неё
  или выбранные схемы.
- **Схемы** — имя (переименовывается при потере фокуса; ссылки
  `#/components/schemas/{name}` по всему документу следуют за новым именем)
  и сама схема: тип, ссылка на другую схему или композиция
  `oneOf` / `anyOf` / `allOf`; формат, nullable, допустимые значения,
  значение по умолчанию, пример, шаблон и ограничения длины, диапазона и
  числа элементов; свойства с признаком обязательности и элементы массива —
  каждое со своей формой схемы.

Всё, чего формы не показывают, — расширения, `examples`, `callbacks`,
`links`, `security` уровня документа и остальное — сохраняется как есть, и
это можно править в исходнике.

## Визуальные правки переписывают текст

Изменение в форме записывается примерно через четверть секунды после
последнего нажатия клавиши: весь документ сериализуется заново. Порядок
ключей при этом сохраняется, но текст раскладывается заново: в YAML —
отступ в 2 пробела и кавычки только там, где нужны; в JSON — форматирование
с отступом в 2 пробела.

**Комментарии в YAML не переживают визуальную правку**, как и собственное
форматирование. Если комментарии файла важны, правьте его в режиме
исходника: там текст сохраняется ровно таким, как набран.

## Swagger 2.0

Документ Swagger 2.0 открывается в режимах исходника и просмотра как
обычно. Визуальный режим вместо форм показывает пояснение — формы работают
с OpenAPI 3 — и кнопку «Convert to OpenAPI 3.1». Преобразование то же, что
справочник использует для показа (см. [`normalize`](core.md#нормализация)):
`host`, `basePath` и `schemes` становятся `servers`, параметры body и form —
`requestBody`, `definitions` — `components.schemas` и так далее. Оно
заменяет текст; чтобы сохранить файл 2.0, сохраните копию.

## Пустой текст

Когда `modelValue` пуст, визуальный режим предлагает «Create a document» —
кнопка записывает минимальный документ OpenAPI 3.1 (название, версия, пустые
`paths`) в формате `newFormat`.

## Проблемы

Панель показывает число ошибок в документе — кнопка «Problems: N» или «No
problems». Она открывает режим исходника, где каждая проблема, найденная
[`validateDocument`](core.md#валидация), показана со своей строкой — и
ошибки, и предупреждения; щелчок ставит курсор на эту строку, а строки с
ошибками отмечены на полях. Для текста, который вообще не разбирается,
вместо этого показываются сообщение и позиция парсера; пока текст снова не
читается, визуальный режим и просмотр показывают это же сообщение.

Проблемы проверяются заново после каждого разбора и каждой правки в форме,
и каждый новый список отправляется событием `issues` — например, чтобы
запретить сохранение документа с ошибками:

```vue
<script setup lang="ts">
import { computed, ref } from 'vue'
import type { DocumentIssue } from '@dskripchenko/openapi'
import { OpenApiEditor } from '@dskripchenko/openapi/vue'

const text = ref(initialYaml)
const issues = ref<DocumentIssue[]>([])
const canSave = computed(() => !issues.value.some((i) => i.severity === 'error'))
</script>

<template>
  <OpenApiEditor v-model="text" @issues="issues = $event" />
  <button :disabled="!canSave">Save</button>
</template>
```

При вводе в очень большой текст (больше 100 000 символов) разбор ждёт
короткой паузы.

## Строки интерфейса

`locale` выбирает строки редактора — с пакетом поставляются английские
(`editorEn`) и русские (`editorRu`), `EDITOR_LOCALES` содержит обе, — а
`labels` заменяет отдельные:

```vue
<OpenApiEditor v-model="text" locale="en" :labels="{ visual: 'Forms', newDocumentTitle: 'Untitled API' }" />
```

Полный словарь для другого языка имеет тип `EditorLabels`:

```ts
import { editorEn, type EditorLabels } from '@dskripchenko/openapi/vue'

const editorDe: EditorLabels = { ...editorEn, visual: 'Formulare', source: 'Quelltext', preview: 'Vorschau' /* … */ }
```

Просмотр — это `OpenApiReference`: строки он берёт из `locale` и
`referenceLabels`; `labels` редактора до него не доходят.

```vue
<OpenApiEditor v-model="text" locale="en" :reference-labels="{ tryIt: 'Run' }" />
```
